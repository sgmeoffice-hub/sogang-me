# Claude로 학과 홈페이지 만들기

서강대학교 기계공학과 홈페이지(me.sogang.ac.kr) 제작 과정 정리 — 다른 학과(화학공학과 등) 참고용

작성: 기계공학과 정석환 (2026-09-09) · 문의: seokhwan@sogang.ac.kr · 완성 사이트: https://me.sogang.ac.kr · 코드 저장소: https://github.com/sgmeoffice-hub/sogang-me

> **한눈에 보기**
> 무엇을 만들었나: 국문·영문 학과 홈페이지 전체 — 학과소개, 교수진, 학부·대학원 과정, 산학 트랙, 게시판 14종, 시설 예약, URECA 인턴 지원, 관리자 모드(/adm), 옛 홈페이지 글 2,275건과 첨부 1.3GB 이관, 학교 도메인 연결.
>
> 누가 만들었나: 교수 1명이 Claude(클로드)에게 말로 지시했고, 코드는 한 줄도 직접 쓰지 않았습니다. 담당자의 일은 ①요구사항을 구체적으로 말하기 ②계정 만들고 버튼 누르기 ③교수님·행정실 의견 모아 전달하기 세 가지였습니다.
>
> 얼마나 걸렸나: 약 2주. 초안 3일 → 교수진 의견 수렴·수정 1주 → 옛 글 이관·도메인 연결 3일. 이후 요청이 올 때마다 30분~2시간 단위로 수정.
>
> 비용: Claude 사용료 약 200달러(약 28만 원) + DB·저장소는 무료 요금제. 호스팅(Vercel)은 무료(Hobby)로 시작했지만 방문·크롤러 요청이 월 100만 건을 넘어 한 달 만에 사이트가 멈춘 적이 있어, 유료(Pro, 월 20달러)를 예산에 잡아 두는 것이 안전합니다. 업체 외주 견적은 700만~2,000만 원이었습니다.


## 1. 시작 전 준비물 — 계정 6개

모든 계정은 개인 계정이 아니라 학과 공용 Gmail로 만듭니다. 담당자가 바뀌어도 그 Gmail 하나만 넘기면 전부 인수인계됩니다. 비밀번호는 홈페이지 코드나 채팅에 절대 적지 말고 학과 드라이브의 비공개 문서에 따로 보관합니다.

| 계정 | 용도 | 요금 | 만들 때 팁 |
| --- | --- | --- | --- |
| 학과 공용 Gmail | 아래 모든 계정의 주인. 알림 메일 수신 | 무료 | 복구 전화번호를 학과 번호로. 2단계 인증 켜기 |
| Claude (claude.ai) | 실제로 홈페이지를 만드는 AI. 웹의 "Claude Code"에서 작업 | 유료 구독(Max 권장) | 구독 후 GitHub 연결(Settings → Connectors) |
| GitHub | 코드와 문서 보관소. 여기 올리면 자동 배포 | 무료 | 리포지토리는 공개(public)여도 되지만 비밀번호·키는 절대 넣지 않음 |
| Vercel | 홈페이지 호스팅(서버). GitHub와 연결하면 저장할 때마다 자동 배포 | 무료(Hobby) → 필요 시 Pro 월 20달러 | GitHub 계정으로 가입 → 리포 import 한 번이면 끝. 무료는 월 요청 100만 건·함수 호출 100만 건 한도 — 넘으면 사이트가 통째로 멈추므로 영상·이미지는 R2에 두고 사용량(Usage)을 매달 확인 |
| Supabase | 데이터베이스(게시글·교수진·예약)와 관리자 로그인 | 무료(DB 500MB, 파일 1GB) | 파일 1GB는 금방 참 → 옛 첨부파일은 아래 R2로 |
| Cloudflare R2 | 옛 홈페이지 첨부파일·이미지 보관(대용량) | 무료(10GB) | 카드 등록이 필요하지만 10GB 이하면 청구 없음. 알림 설정 권장 |
| (선택) Resend | 예약·지원 접수 알림 메일 발송 | 무료(월 3천 통) | 학과 도메인 인증을 안 하면 학과 Gmail로만 수신 → Gmail 필터로 행정실에 전달 |
| (선택) Anthropic API 키 | 국문→영문 자동 번역 품질(없으면 무료 번역기 사용) | 사용량 과금(소액) | Vercel 환경변수에만 넣음 |


## 2. 전체 흐름 8단계

각 단계에서 담당자가 한 일과 Claude에게 실제로 했던 말을 적었습니다. 그대로 따라 하셔도 됩니다.


### 1단계. 옛 홈페이지 자료 확보 (2~3일, 업체 회신 대기)

- 현재 홈페이지 호스팅 업체에 "데이터베이스 덤프(SQL) + 웹 파일(첨부·이미지 포함) 전체 백업"을 요청해 구글 드라이브에 받아 둡니다. 기계과는 그누보드(국내 게시판 프로그램) MySQL 덤프 + 파일 1.9GB였습니다.
- 이 백업이 있어야 옛 게시글·첨부파일을 새 사이트로 옮길 수 있습니다. 없으면 Claude가 옛 사이트를 직접 긁어와야 해서 느리고 불완전합니다.
- 호스팅 계약 만료일을 확인해 두세요. 만료 전에 옮겨야 하고, 만료 후에도 1~2달은 옛 사이트를 볼 수 있게 남겨 두면 안전합니다.
- 옛 홈페이지의 메뉴 구조, 색상, 로고 파일(학교 공식 시그니처), 자주 쓰는 사진을 미리 모아 두면 초안 품질이 올라갑니다.


### 2단계. 첫 지시로 초안 만들기 (반나절)

claude.ai → Claude Code에서 새 저장소를 만들며 아래처럼 지시했습니다. 기술 용어(Next.js, Supabase)는 몰라도 됩니다 — Claude가 알아서 고르고 설명해 줍니다.

```
서강대학교 화학공학과 홈페이지를 새로 만들어줘.
- 국문/영문 두 언어, 모바일에서도 잘 보이게
- 메뉴는 기존 홈페이지(주소: ...)와 같은 순서로: 학과소개 / 교수진 / 학부과정 / 대학원과정 / 학과게시판 / 동문회
- 디자인: 서강대 공식 색(카디널 레드)과 시그니처 로고 사용, 깔끔하고 현대적으로
- 게시판(공지·연구성과·수상·장학·갤러리 등)과 교수진은 관리자 화면(/adm)에서 행정선생님이 직접 편집할 수 있게
- 시설 예약, 학부연구 인턴 지원 같은 신청 기능 포함
- 무료 요금제로 운영 가능하게 구성하고, 내가 눌러야 할 계정 설정은 단계별로 알려줘
```

- Claude가 만든 임시 주소(예: xxx.vercel.app)로 바로 결과를 볼 수 있습니다. 첫 초안은 하루 안에 나옵니다.
- 기계과의 경우 "Physical AI(로봇+AI)" 같은 키워드를 초기 지시에 강조했더니 내용이 한 분야로 치우쳤습니다. 학과의 세부 분야를 처음부터 균형 있게 나열해 주세요.


### 3단계. 교수진·행정실 의견 수렴과 반복 수정 (1주)

- 초안 주소를 전체 교수님께 메일로 보내 의견을 받았습니다. "Claude가 이해할 수 있게 화면 캡처와 함께 구체적으로" 부탁하는 문장을 꼭 넣으세요.
- 들어온 의견은 한 번에 모아 Claude에게 전달합니다(메일을 PDF로 저장해 그대로 첨부해도 됩니다). 예: "박현주 선생님 요청 6건 — 첨부 PPT 참고. 6번은 관리자 전용으로 하고 홈페이지에는 안내 문구만."
- 실제로 들어온 의견 유형: 메인 영상 교체, 특정 분야 편중 수정, 공지사항을 일반/학사로 분리, 예약 시스템 사용성(30분 단위, 수정 모드, 달력형), 동문 소식 보강, BK21 링크 복원, 하단에 학과 메일 표기.
- 큰 변경(레이아웃·여러 페이지)은 "미리보기 주소로 먼저 보여줘"라고 하면 실서비스에 반영하기 전에 확인할 수 있습니다.


### 4단계. 옛 게시글·첨부파일 이관 (1일)

- 1단계에서 받은 백업의 드라이브 공유 링크를 Claude에게 주고 "옛 게시판을 전부 새 사이트로 옮겨줘"라고 하면 됩니다. 기계과는 게시글 2,275건, 첨부·이미지 3,216개(1.27GB)가 하루 만에 옮겨졌고, 건수 대조까지 Claude가 했습니다.
- 개인정보가 든 게시판(인턴 지원서, 학번·연락처가 있는 명단 등)은 공개 게시판으로 옮기지 말고 관리자 전용으로 넣거나 제외하도록 미리 말해 두세요. 기계과는 URECA 지원 기록 12년치(1,146건)를 관리자 화면에만 넣었습니다.
- 옛 첨부파일은 Supabase 무료 한도(1GB)를 넘기므로 Cloudflare R2(무료 10GB)로 옮기는 것이 정답이었습니다. 처음부터 "첨부파일은 R2에"라고 하면 두 번 일하지 않습니다.
- 이관 직전 며칠 사이 옛 사이트에 새로 올라온 글·예약이 있으면 Claude에게 "백업 이후 추가된 글 동기화"를 한 번 더 시킵니다.


### 5단계. 기능 다듬기 — 관리자 모드·예약·지원·알림

- 관리자 모드(/adm): 학과 Gmail로 로그인해 게시글·교수진·배너·설정을 편집. 워드처럼 쓰는 편집기, 사진 업로드, 유튜브 주소 넣으면 영상 임베드, 국문 쓰면 영문 자동 번역.
- 시설 예약: 홈페이지에서 신청 → 관리자가 승인. 30분 단위, 겹침 방지, 관리자용 반복(매주) 등록, 시설별 달력.
- 알림 메일: 예약·지원이 들어오면 학과 Gmail로 메일 → Gmail 필터로 행정선생님 학교 메일에 자동 전달.
- 행정선생님이 쓰실 것: 관리자 화면 안의 안내 문구, 더블클릭 바로가기 파일(옛 홈페이지 열기, 관리자 열기), 운영 매뉴얼(docs/OPERATIONS.md).


### 6단계. 학교 도메인 연결 (2~3일, 정보통신원 회신 대기)

1. Vercel에서 도메인(예: che.sogang.ac.kr) 추가 → Vercel이 알려주는 CNAME·TXT 값을 받습니다.
2. 정보통신원(디지털정보처)에 "이 도메인을 아래 값으로 연결해 달라"는 메일을 보냅니다. Claude에게 "복붙할 수 있게 평문으로 메일 초안 써줘"라고 하면 됩니다. 옛 사이트를 남겨 둘 별도 주소(예: che-old)도 같이 요청하면 편합니다.
3. 연결 후 Claude에게 시킬 마무리: 옛 주소로 들어오는 링크를 새 글로 자동 연결(리다이렉트), 사이트맵 생성, 구글 서치콘솔 등록, 검색엔진에서 옛 사이트 대신 새 사이트가 나오게.
4. 연결 직후 일부 컴퓨터에서 몇 시간 옛 사이트가 보이는 것은 정상(DNS 캐시)입니다.


### 7단계. 전체 점검 시키기

- 기능이 다 붙은 뒤 Claude에게 "홈페이지와 관리자 모드 전체를 검토해서 버그·논리 오류·보안 문제를 찾아 고쳐줘"라고 한 번 시키세요. 기계과는 이 한 번으로 37건을 찾아 고쳤고, 그중에는 예약자 전화번호가 외부에서 조회될 수 있던 개인정보 문제도 있었습니다.
- 점검 결과 중 "데이터베이스 설정(SQL)을 직접 실행해 달라"는 안내가 나오면 Supabase 화면의 SQL Editor에 붙여넣고 Run 한 번이면 됩니다. Claude가 붙여넣을 내용을 그대로 줍니다.


### 8단계. 운영과 인수인계

- Claude 작업 세션은 매번 새로 시작되므로, 저장소 안의 두 문서가 기억 역할을 합니다. CLAUDE.md = 지켜야 할 규칙(디자인 고정, 메뉴 순서, 게시 금지 항목, 두 언어 동시 반영). docs/HANDOFF.md = 지금까지 한 일과 남은 일. 새 세션에서 "HANDOFF.md 읽고 이어서 해줘"라고 하면 됩니다.
- 백업: 코드는 GitHub, 옛 파일은 R2와 드라이브 원본, 데이터베이스는 주 1회 자동 덤프(Google Apps Script)로 드라이브에 저장하는 구성을 만들어 두었습니다.
- 운영 매뉴얼(docs/OPERATIONS.md)에 구조·계정·장애 대응·Claude 지시 방법을 정리해 두고, 계정 비밀번호 목록은 리포에 넣지 않고 드라이브 비공개 문서로 따로 관리합니다.

## 3. Claude에게 잘 시키는 요령 10가지

1. 화면 캡처 + 구체적인 문장. "여기 이상해"보다 "동문 소식 카드 썸네일이 연락처 표 캡처로 보임. 얼굴 사진만 보이게 해줘"가 한 번에 됩니다.
2. 의견은 모아서 한 번에. 메일·PPT를 그대로 첨부하고 "이 중 6번은 이렇게 바꿔서"처럼 판단만 덧붙이면 됩니다.
3. "배포까지 해줘"라고 말하기. 그래야 실제 사이트에 반영되고 확인까지 해 줍니다.
4. 비밀번호·API 키는 채팅에 올리지 않기. 저장소가 공개라 코드에 들어가면 안 됩니다. 키는 Vercel/Supabase 화면에 직접 넣고, Claude에게는 "넣었어"라고만 알립니다.
5. 규칙은 CLAUDE.md에 적어 두기. 예: 디자인 테마 임의 변경 금지, 메뉴 순서 유지, 학생 개인정보 게시 금지, 국문·영문 함께 반영, 모바일 확인.
6. 세션이 바뀌면 "docs/HANDOFF.md 읽고 이어서". 작업이 끝나면 "HANDOFF 갱신해서 커밋해줘".
7. 큰 개편은 "미리보기 주소로 먼저". 작은 수정은 바로 반영해도 됩니다.
8. "직접 스크린샷 찍어서 검수하고 배포해"라고 요구하기. Claude가 로컬에서 화면을 찍어 확인한 뒤 배포합니다.
9. 게시글·교수진 같은 데이터는 관리자 모드(/adm)에서 행정선생님이 고치는 것이 원칙. 대량 작업(수백 건 재분류 등)만 Claude에게.
10. "무료 한도 넘는 거 없어?"를 매달 물어보기. 저장 용량·메일 발송량은 Claude가 확인해 주지만, Vercel 사용량(요청 수·함수 호출)은 Vercel 대시보드 Usage 화면을 담당자가 직접 봐야 합니다. 한도의 80%를 넘으면 미리 Pro로 올리는 편이 안전합니다.


## 4. 겪었던 문제와 해결 — 화공과는 처음부터 피할 수 있는 것들

| 문제 | 원인 | 해결 / 처음부터 이렇게 |
| --- | --- | --- |
| 저장했는데 사이트가 안 바뀜 | GitHub 자동화 봇이 만든 커밋은 Vercel이 배포하지 않음 | 소유자 계정으로 커밋. Claude에게 "배포됐는지 확인"까지 요청 |
| 첨부파일 업로드가 어느 날 실패 | Supabase 무료 저장소 1GB 초과 | 옛 첨부파일은 처음부터 Cloudflare R2(10GB 무료)로 |
| 예약 알림 메일이 안 옴 | 환경변수의 API 키가 복사 중 잘려 들어감 | 키를 넣은 뒤 "테스트 메일 보내서 확인해줘" |
| 한국인이 영문 페이지에 갇힘 | 옛 영문 링크로 들어오면 언어를 영어로 기억하던 버그 | 언어는 사용자가 전환 버튼을 눌렀을 때만 기억하도록 |
| 구글에 남은 옛 주소가 403 오류 | 옛 게시판 주소 형식을 새 사이트가 모름 | 도메인 연결 때 "옛 주소 리다이렉트"를 같이 요청 |
| 예약자 전화번호가 외부 조회 가능 | DB 공개 읽기 권한이 컬럼을 못 가림 | "개인정보 컬럼 노출 점검"을 전체 감사 항목에 포함 |
| 도메인 이전 후 옛 사이트를 못 봄 | 옛 서버는 옛 주소로만 응답 | 행정선생님용 더블클릭 바로가기(bat) 파일로 해결 |
| 교수 프로필 표 캡처가 카드 썸네일로 노출 | 옛 글의 첨부 이미지를 그대로 썸네일로 사용 | 이관 후 홈 화면 카드 썸네일을 한 번 훑어보기 |
| 어느 날 사이트가 통째로 멈춤(402 오류) | Vercel 무료 한도(월 요청 100만 건) 초과 — 홈 배경 영상이 5초마다 다시 요청되던 것 + 크롤러가 옛 글 4,700개를 반복 수집 | 영상·이미지 파일은 처음부터 R2에서 서빙, AI 수집 봇 차단, 페이지 캐시 주기를 길게. 그래도 넘으면 Pro(월 20달러)로 |


## 5. 화학공학과가 따라 하는 두 가지 방법


### 방법 A. 기계과 홈페이지를 틀로 삼기 (권장 — 가장 빠름, 2~3일)

기계과 코드 저장소(https://github.com/sgmeoffice-hub/sogang-me)는 공개되어 있어 그대로 복제할 수 있습니다. 구조·관리자 모드·예약·게시판·번역·보안 점검이 이미 끝난 상태에서 시작하므로, 화공과에 맞게 바꾸는 작업만 하면 됩니다.

1. 화공과 공용 Gmail로 GitHub·Vercel·Supabase 계정을 만듭니다(1장 표).
2. GitHub에서 기계과 저장소를 Fork(복제)한 뒤 Claude Code에서 그 저장소를 열고 아래처럼 지시합니다.

```
이 저장소는 기계공학과 홈페이지야. 화학공학과용으로 바꿔줘.
- 학과명·영문명·연락처·주소·로고 문구를 화학공학과로
- 기계과의 4대 분야(설계·역학/열·유체/제어·로보틱스/생산·제조) 구조를 화공과 세부 분야로 교체: (분야 목록)
- 교수진·연구실은 첨부한 명단으로 새로 넣고, 기계과 데이터는 전부 비우기
- 메뉴는 화공과 옛 홈페이지(주소: ...) 순서대로
- 새 Supabase 프로젝트를 쓸 거야. 내가 만들어야 할 것과 붙여넣을 SQL을 순서대로 알려줘
- 끝나면 Vercel 미리보기 주소로 보여줘
```

- 기계과 CLAUDE.md·docs/OPERATIONS.md·docs/HANDOFF.md의 내용을 화공과 상황에 맞게 고쳐 달라고 하면 운영 문서까지 한 번에 갖춰집니다.
- 주의: 복제한 저장소에 기계과 데이터베이스 주소나 키는 들어 있지 않습니다(환경변수). 화공과 Supabase/Vercel을 새로 연결해야 합니다.


### 방법 B. 처음부터 만들기 (1~2주)

2장 2단계의 첫 지시문으로 새로 시작합니다. 디자인 자유도는 높지만 의견 수렴·이관·점검을 처음부터 다시 겪습니다. 기계과 사이트를 "이런 느낌으로"라며 참고 주소로 주면 시간이 줄어듭니다.


## 6. 첫 주 체크리스트

- ☐ 학과 공용 Gmail 준비(복구 전화 = 학과 번호, 2단계 인증)
